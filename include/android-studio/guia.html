INSTALACAO

LINUX

No site oficial você enconta TODAS versões do ANDROID STUDIO


Baixando

Fazer o download da versão desejada na pagina oficial.

A versao LINUX 2.3.2 está disponivel CLICANDO NESSE LINK

Descompactando

Descompacte o arquivo conforme o comando abaixo: 
 // SE FOR TAR
    $ sudo tar zxvf android-studio-2020.3.1.24-linux.tar.gz -C /home/SEU-USUARIO/
    // SE FOR ZIP
    $ sudo unzip android-studio-2020.3.1.24-linux.zip -d /home/SEU-USUARIO/
Deverá ficar assim: /home/SEU-USUARIO/android-studio

Instalando

Torando o arquivo studio.sh executável para instalação. 
$ sudo chmod +x /home/teste/android-studio/bin/studio.sh
    $ ./studio.sh
Uma janela pop-up será exibida solicitando as configurações de instalação. No meu caso específico, é uma instalação nova, então vou selecionar Não tenho uma versão anterior do Studio ou não quero importar minhas configurações.

Se você escolher importar as configurações de qualquer maneira, pode ser necessário fechar qualquer projeto antigo aberto para obter um SDK Android funcional.

VARIAVEL - ANDROID_HOME

$ cd 
    $ sudo nano ~/.bash_profile
insira a variavel abaixo: 
    export ANDROID_SDK_ROOT=/home/teste/Android/Sdk
    export ANDROID_HOME=/home/teste/Android/Sdk
    export PATH=${PATH}:$ANDROID_HOME/tools:$ANDROID_HOME/platform-tools
recarregue o arquivo 
$ source ~/.bash_profile
