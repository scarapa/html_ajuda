1. operadores

OPERADORES

  • isEqualTo
    • Retorna documentos onde o campo é exatamente igual ao valor informado.
  • isGreaterThan
    • Retorna documentos onde o campo é maior que o valor informado.
  • isGreaterThanOrEqualTo/li> Retorna documentos onde o campo é maior ou igual ao valor informado.
  • isLessThan
    • Retorna documentos onde o campo é menor que o valor informado.
  • isLessThanOrEqualTo
    • Retorna documentos onde o campo é menor ou igual ao valor informado.
  • arrayContains
    • Retorna documentos onde um campo array contém um valor específico.
  • arrayContainsAny
    • Retorna documentos onde um campo array contém qualquer valor de uma lista.
  • whereIn
    • Retorna documentos onde o campo é igual a qualquer um dos valores de uma lista.
  • whereNotIn
    • Retorna documentos onde o campo não é igual a nenhum dos valores de uma lista.
  • isNull
    • Retorna documentos onde o campo é nulo.

    Abaixo o exemplo de implementação de um metodo findWhere() na classe FirebaseHelper; onde é possivel enviar por parametro um lista contendo o campo, operador e o valor 
    static Future<List<Map<String, dynamic>>> findWhere(String collection, String email, List<Map<String, dynamic>> where) async {
  
  List<Map<String, dynamic>> _lista = [];
  FirebaseFirestore db = await FirebaseDatabaseHelper.get();
  
  try {
    // Inicializando a consulta
    Query query = db.collection(collection).doc(email).collection('subcolecao');
  
    // Aplicando as condições do 'where'
    for (var condition in where) {
      if (condition.containsKey('field') && condition.containsKey('operator') && condition.containsKey('value')) {
        String field = condition['field'];
        String operator = condition['operator'];
        dynamic value = condition['value'];
    
        switch (operator) {
        case '==':
          query = query.where(field, isEqualTo: value);
          break;
        case '>':
          query = query.where(field, isGreaterThan: value);
          break;
        case '>=':
          query = query.where(field, isGreaterThanOrEqualTo: value);
          break;
        case '<':
          query = query.where(field, isLessThan: value);
          break;
        case '<=':
          query = query.where(field, isLessThanOrEqualTo: value);
          break;
        case 'array-contains':
          query = query.where(field, arrayContains: value);
          break;
        case 'array-contains-any':
          query = query.where(field, arrayContainsAny: value);
          break;
        case 'in':
          query = query.where(field, whereIn: value);
          break;
        case 'not-in':
          query = query.where(field, whereNotIn: value);
          break;
        case 'isNull':
          query = query.where(field, isNull: value);
          break;
        default:
          print("Operador não suportado: $operator");
          break;
        }
      } else {
        print("Condição inválida: $condition");
      }
    }
  
    // Executando a consulta
    QuerySnapshot registros = await query.get();
    for (var doc in registros.docs) {
      _lista.add(doc.data() as Map<String, dynamic>);
    }
    return _lista;
  } catch (e) {
    print("ERRO FIREBASE: $e");
    throw e;
  }
}
    OBSERVAÇÃO
    No Firebase Firestore, infelizmente não existe um operador LIKE nativo como no SQL. 😕 Mas tem algumas alternativas pra conseguir algo semelhante!

    Se você quer buscar por strings que começam com determinado texto, pode usar um intervalo com esses operadores.
    Query query = db.collection(collection)
  .where('nome', isGreaterThanOrEqualTo: 'jo')
  .where('nome', isLessThanOrEqualTo: 'jo\uf8ff'); // O caractere especial é o truque!
    ✅ Isso retorna todos os documentos onde o campo nome começa com jo.
    ⚠️ Essa técnica funciona apenas para buscas por prefixo, não no meio ou no final da string.

    Resumo prático:
