CONFIGURACAO

ARMAZENAMENTO

Os projetos estao armazenados em outro disco, para isso precisamos montar a particao 
#desmontar particao, caso esteja montada
$ sudo umount /dev/sdb1

#levantar montagem de disco no padrao NTFS
$ sudo ntfs-3g /dev/sdb1 /media/drive


APONTAMENTO

precisamos apontar no lampp para a nova pasta onde estao os projetos, necessario abrir o arquivo de configuracao. 
$ sudo nano /opt/lampp/etc/httpd.conf
procurar pela linha DocumentRoot "/opt/lampp/htdocs" e alterar para o novo caminho, no meu caso /media/drive/www 
DocumentRoot "/media/drive/www"
<Directory "/media/drive/www">
    Options Indexes FollowSymLinks ExecCGI Includes
    AllowOverride All
    Require all granted
</Directory>

SERVICO

para levantar o lampp, basta executar o comando: 
$ sudo /opt/lampp/lampp start

INICIALIZACAO

Para inicializacao CORRETA de tudo basta seguir os passos: 
#montar particao
$ sudo ntfs-3g /dev/sdb1 /media/drive
#iniciar lampp  
$ sudo /opt/lampp/lampp start
