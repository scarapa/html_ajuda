O Tinker é uma ferramenta de linha de comando poderosa e interativa (um REPL, ou Loop de Leitura-Avaliação-Impressão) que permite aos desenvolvedores interagir com toda a sua aplicação Laravel em tempo real.
Desenvolvido pelo pacote PsySH, ele está incluído em todos os novos projetos Laravel por padrão.

Como Acessar o Tinker
Para iniciar o Tinker, você pode usar o Artisan, a interface de linha de comando do Laravel. Basta executar o seguinte comando no terminal, dentro do diretório do seu projeto Laravel: 
$ php artisan tinker
Vamos supor que eu tenha essa classe abaixo: 
class ParkModel extends Model {
  
  use HasFactory;

  protected $table = 'parks';

  public $timestamps = false;
  // NECESSARIO PARA USAR O TICKER
  // Se não tiver isso, o Laravel vai lançar erro de MassAssignmentException.
  protected $fillable = [
    'uuid',
    'id_user',
    'ds_documento',
    'ds_nome',
    'ds_cep',
    'id_cidade',
    'ds_bairro',
    'ds_endereco',
    'ds_complemento',
  ];

  protected $hidden = [
    'dt_created',
    'dt_updated',
    'dt_deleted',
  ];
}
para inserir um novo registro na tabela parks, eu posso fazer assim: 
App\Models\ParkModel::create([

  'id_user'=> 2,
  'ds_documento'=>'41625687000138',
