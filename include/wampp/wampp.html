CONFIGURACAO PASTA HTDOCS

Configurando para deixar a pasta www/htdocs em outro pasta, em outro disco('D:\projetos\php').

Pare o servidor Apache.

httpd.conf

Vá até a pasta de instalação do Wampp64 (geralmente C:\wampp64\bin\apache\apacheX.X.X\conf) e abra o arquivo httpd.conf com um editor de texto (como o Notepad++).

Procure pela linha que começa com DocumentRoot (geralmente na linha 215) e altere o caminho para a nova pasta desejada. Por exemplo: 
  DocumentRoot "d:/projetos/php/"
  <Directory "d:/projetos/php/">
  Options +Indexes +FollowSymLinks -Multiviews
  AllowOverride all
  Require all granted
  </Directory>

httpd-vhosts.conf

comentar todo o conteudo do arquivo httpd-vhosts.conf que fica na pasta C:\wampp64\bin\apache\apacheX.X.X\conf\extra, para evitar conflitos.

CONFIGURACAO PARA PROJETOS LARAVEL

Entendendo a solução : Atualmente tenho varios projetos php que estao dispostos nos caminhos abaixos:
  1. D:\projetos\php\cep_laravel
  2. D:\projetos\php\padel_laravel
  3. D:\projetos\php\parkflow-laravel-backend
  4. D:\projetos\php\futebol_laravel
e como tenho o wampp64 instalado , acesso aos projetos localmente da seguinte forma:
  1. http://127.0.0.1/cep_laravel/
  2. http://127.0.0.1/padel_laravel/
  3. http://127.0.0.1/parkflow-laravel-backend/
  4. http://127.0.0.1/futebol_laravel/
mas eu desejo mudar o caminho desses projetos pondo todos dentro de uma pasta 'laravel' deixando da seguinte forma:
  1. D:\projetos\php\laravel\cep
  2. D:\projetos\php\laravel\padel
  3. D:\projetos\php\laravel\parkflow
  4. D:\projetos\php\laravel\futebol
entretanto quero continuar acessando quase da mesma forma:
  1. http://127.0.0.1/cep/
  2. http://127.0.0.1/padel/
  3. http://127.0.0.1/parkflow/
  4. http://127.0.0.1/futebol/
Mas para isso preciso configurar o seguintes arquivos no Wampp64; como referencia usarei o projeto 'cep'; mas isso precisa ser feitos em TODOS os projetos que estao dentro da pasta 'laravel'.
  1. wampp64\bin\apache\apacheX.X.X\conf\httpd.conf
  2. wampp64\bin\apache\apacheX.X.X\conf\extra\httpd-laravel.conf
  3. projetos\php\laravel\cep\.htaccess
  4. projetos\php\laravel\cep\public\.htaccess

httpd.conf

inclua o arquivo de configuração do laravel, adicionando a linha acima do documentRoot: 
# PROJETOS LARAVEL - PRECISA ESTAR ANTES DO DOCUMENTROOT
Include conf/extra/httpd-laravel.conf
...
DocumentRoot "d:/projetos/php/"
<Directory "d:/projetos/php/">
	Options +Indexes +FollowSymLinks -Multiviews
    AllowOverride all
    Require all granted
</Directory>

httpd-laravel.conf

Crie o arquivo 'httpd-laravel.conf' na pasta 'conf/extra'; replique o conteudo abaixo, adaptando os paths para cada projeto laravel que voce tiver: 
# ======================================================
# Reservar paths antes do DocumentRoot
# ======================================================

Alias /cep "D:/projetos/php/laravel/cep/public"
<Directory "D:/projetos/php/laravel/cep/public">
    Options FollowSymLinks
    AllowOverride All
    Require all granted
</Directory>

projetos\php\laravel\cep\.htaccess

COMENTE ou DELETE esse arquivo '.htaccess' que esta na raiz do projeto laravel (na pasta 'cep').

projetos\php\laravel\cep\public\.htaccess

No arquivo '.htaccess' que esta dentro da pasta 'public', copie e substitua todo o conteudo pelo conteudo abaixo: 
<IfModule mod_rewrite.c>
    <IfModule mod_negotiation.c>
        Options -MultiViews -Indexes
    </IfModule>

    RewriteEngine On
    RewriteBase /cep/

    # NÃO REESCREVER ARQUIVOS PHP EXISTENTES
    RewriteCond %{REQUEST_FILENAME} -f
    RewriteRule \.php$ - [L]

    # Handle Authorization Header
    RewriteCond %{HTTP:Authorization} .
    RewriteRule .* - [E=HTTP_AUTHORIZATION:%{HTTP:Authorization}]

    # Handle X-XSRF-Token Header
    RewriteCond %{HTTP:x-xsrf-token} .
    RewriteRule .* - [E=HTTP_X_XSRF_TOKEN:%{HTTP:X-XSRF-Token}]

    # Redirect Trailing Slashes If Not A Folder...
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_URI} (.+)/$
    RewriteRule ^ %1 [L,R=301]

    # Send Requests To Laravel Front Controller
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteRule ^ index.php [L]
</IfModule>
Necessario alterar a linha 7: 'RewriteBase /cep/' para o nome do projeto que voce estiver configurando.
