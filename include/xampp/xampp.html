AUTOMATIZAÇÃO - ubuntu 20

Utilizando o ubuntu e um segundo disco a tarefa de montar o HD e levantar os servicos se torna monotona.
Vamos criar um script de inicializacao;

criar arquivo script servidor.sh e salvar em /etc/init.d 
$ touch servidor.sh
o arquivo ira conter o codigo abaixo: 
#!/bin/bash
#desmontar particao, caso esteja montada
$ sudo umount /dev/sdb1

#levantar montagem de disco no padrao NTFS
$ sudo ntfs-3g /dev/sdb1 /media/drive

#levantar os servicos do xampp/lammp
$ sudo /opt/lampp/lampp start
conceder permissões para executar este arquivo. 
$ chmod +x servidor.sh
incluir o script servidor.sh na inicialização do sistema 
$ cd /etc/init.d/
$ update-rc.d servidor.sh defaults 80

ATUALIZAR PHP

Execute o seguinte comando para visualizar as informações do PHP: 
$ php -i | grep 'php.ini'
  PHP Warning:  Module "gd" is already loaded in Unknown on line 0
  Configuration File (php.ini) Path => /etc/php/8.1/cli
  Loaded Configuration File => /etc/php/8.1/cli/php.ini

Atualizar o repositório de pacotes

$ sudo apt update
$ sudo apt install software-properties-common
$ sudo add-apt-repository ppa:ondrej/php
$ sudo apt update
Após adicionar o repositório, instale o PHP 8.2: 
$ sudo apt install php8.2
Instalar módulos adicionais do PHP 8.2 
$ sudo apt install php8.2-cli php8.2-common php8.2-mysql php8.2-xml php8.2-curl php8.2-zip php8.2-gd php8.2-mbstring

Configurar o PHP 8.2 com Apache

Se você estiver utilizando o LAMP, precisará habilitar o PHP 8.2 para o Apache: 
  $ sudo a2dismod php8.1  # Desativa o PHP 8.1, se estiver ativado
  $ sudo a2enmod php8.2   # Ativa o PHP 8.2
Após habilitar o PHP 8.2, reinicie o Apache para que as alterações entrem em vigor; caso ainda não esta apontando para a nova versao execute o seguinte comando para configurar a versão 8.2 como padrão: 
$ sudo update-alternatives --set php /usr/bin/php8.2

ERRO ACESSO REMOTO PHPMYADMIN

Acessar o arquivo responsável pela configuracao

$ sudo nano /opt/lampp/etc/extra/httpd-xampp.conf
A configuracao deverá ficar comentada a linha verde e adicionada a linha opcao em VERMELHA 
Alias /phpmyadmin "/opt/lampp/phpmyadmin"

# since XAMPP 1.4.3
<Directory "/opt/lampp/phpmyadmin">
    AllowOverride AuthConfig Limit
    #Require local
    Require all granted
    ErrorDocument 403 /error/XAMPP_FORBIDDEN.html.var
</Directory>
